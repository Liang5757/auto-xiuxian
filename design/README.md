# 当前界面设计

当前截图于 2026-11-25 从 v0.4.0 源码启动的 Electron + React 实际窗口通过 Electron 直接导出，不含鼠标指针；游戏未启动且各功能关闭：

- `current/dispatch-v0.4.0.png`：自动派遣。
- `current/farm-v0.4.0.png`：自动收种。
- `current/clicker-v0.4.0.png`：连点器。
- `current/speed-v0.4.0.png`：内置游戏变速。

页面在 desktop/src/components/，就近样式在 index.module.scss。

默认窗口尺寸为 800 × 570 逻辑像素，最小尺寸为 760 × 540。侧栏宽 156，内容留白 24，卡片间距 12～16，圆角 12。白色侧栏与卡片置于冷灰背景上。紫色只用于主要交互与选中态。标题 22，分区标题 14～15，正文 13，辅助信息 11～12。

侧栏依次提供自动派遣、自动收种、连点器和游戏变速入口，底部提供派遣与收种总开关。自动派遣和自动收种均包含检测间隔、状态开关、成功/失败/地图三项统计以及运行记录。空记录居中显示。连点器使用独立页面，运行时禁用参数设置。游戏变速提供独立开关、倍率输入、常用倍率和恢复原速。图标统一使用细线，窗口图标使用飞剑祥云，设计说明见 icon.md。
