# 当前界面设计

当前定稿截图位于 current/dispatch.png 与 current/clicker.png。两张图片均来自本次 Rust 程序的实际窗口，使用真实的关闭状态与计数。

默认内容尺寸为 800 × 540 逻辑像素。侧栏宽 156，内容留白 24，卡片间距 12～16，圆角 12。白色侧栏与卡片置于冷灰背景上。紫色只用于主要交互与选中态。标题 22，分区标题 14～15，正文 13，辅助信息 11～12。

自动派遣包含状态开关、成功/失败/地图三项统计以及运行记录。空记录居中显示。连点器使用独立页面，运行时禁用参数设置。图标统一使用细线，窗口图标使用紫色菱形标志。

原来的 approved-dispatch.png 作为历史设计保留。当前界面实现在 src/ui/mod.rs，界面样式由 Rust 绘制，应用图标位于 assets/app.png 与 assets/app.ico，ICO 含 16 至 256 像素共七档尺寸并嵌入 EXE 资源。
