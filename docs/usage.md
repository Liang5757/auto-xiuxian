# 使用说明

[返回首页](../README.md)

若无法访问 Release，请确认已登录具有仓库访问权限的 GitHub 账号。每个 Release 提供 `SHA256SUMS.txt`，可用于核验下载文件。

所有功能启动时默认关闭。检测间隔、连点器配置和变速倍率会保存；派遣与收种的成功、失败计数及各自最近 100 条日志仅保留于本次运行，完全退出后清空。

## 自动派遣

一次检查按照以下顺序执行。

1. 定位游戏窗口，检查是否处于战斗页。
2. 识别小队返回的蓝色提示，有返回的小队才进入派遣流程。
3. 记录原地图，打开世界地图并进入蛮荒之地。
4. 检查三支小队的状态，收取已返回的小队。
5. 校验宠物列表变化及选中头像，重新派遣。
6. 核对出发状态，返回原挂机地图。

自动派遣与自动收种的检测间隔均可在各自页面输入，停止输入后自动保存，单位 s，范围为 1～86400，默认 30。运行中修改会调整当前等待时长，退出应用后保留，下次启动自动恢复。

每轮操作只计一次成功或失败，空轮询不计数。失败后保持开关开启，等待设定的检测间隔后继续重试。上一轮未完成回程时，下一轮先尝试恢复原地图。

时空原点使用已知回程位置。首次在其他地图使用时，按运行记录提示，在世界地图中将鼠标指向原地图图标并按 F8。本次派遣会话内会缓存该位置。

## 自动收种

进入侧边栏的“自动收种”，从原挂机地图的战斗页开启。按设定间隔检查成熟提示（默认 30 秒），进入洞府的灵植园收获成熟作物，并在全部空坑补种高级灵谷。回程标记方式与派遣相同。侧边栏底部总开关可同时开启或关闭派遣和收种（部分开启时点击会同时关闭），两项任务独立启停、分别计数并记录日志，操作游戏时依次执行。

## 连点器

- 点击间隔支持 30～60000 毫秒，停止输入后自动保存。鼠标按键、热键选择后立即保存，下次启动自动恢复配置。
- 支持左键、右键，启停热键可选 F6、F7、F9。
- 仅在鼠标指向游戏所属窗口时点击。
- 自动派遣或自动收种检查及操作期间暂停连点，避免任务同时操作游戏。
- 运行时锁定参数设置，停止后可修改。

## 游戏变速

在“游戏变速”页面设置 0.1～10 倍速（最多一位小数），点击“应用倍率”保存，开启独立开关后生效。提供常用倍率和“恢复原速”，运行中也可应用新倍率；不会改变助手本身的检测间隔或连点间隔。

变速模块由本项目源码构建，随助手内置，不使用 OpenSpeedy 的程序、DLL、目录、共享内存或协议。支持 32/64 位游戏，针对游戏进程的 QueryPerformanceCounter、GetTickCount、GetTickCount64 和 timeGetTime 调整时间流速，不改变助手自身的计时。

只保留一个《懒人修仙传》窗口。倍率会保存，助手或游戏重启后需手动开启。隐藏到托盘继续变速，关闭变速或正常退出恢复原速；控制进程异常退出时，游戏内模块也会自动恢复为 1 倍速。为保持游戏时钟连续，关闭后模块保留在游戏中直至游戏退出。如果游戏已加载其他变速工具的 DLL，请重启游戏后使用，避免叠加计时钩子。

## 后台运行与退出

点击“后台运行”、最小化或关闭助手窗口都会隐藏到系统托盘，已开启的任务继续执行。双击托盘图标或再次打开 EXE，可恢复已有窗口。

从托盘菜单选择“退出”，或在助手窗口按 Ctrl+Q，可完全退出。退出时恢复游戏原速、停止连点，并等待派遣与收种任务停止。

| 热键         | 用途                           |
| ------------ | ------------------------------ |
| Esc          | 停止自动派遣和自动收种         |
| F6 / F7 / F9 | 使用连点器中选定的热键启停连点 |
| F8           | 按提示标记原地图的回程位置     |
| Ctrl+Q       | 在助手窗口中完全退出           |

游戏最小化时，助手会短暂还原游戏窗口进行检查，然后重新最小化。发行版请求管理员权限，用于操作管理员模式运行的游戏。
